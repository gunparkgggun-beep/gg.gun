# 𝗚𝗚/𝗚ᴜɴ 枪 — Discord Cloner Bot policies

This package contains draft Terms of Service and Privacy Policy files.

## Publish on GitHub Pages
1. Create a public GitHub repository, such as `gg-gun-cloner-policies`.
2. Upload `terms.html` and `privacy.html` (HTML versions are recommended for direct public pages).
3. In the repository, open **Settings → Pages**.
4. Choose **Deploy from a branch**, branch `main`, folder `/(root)`, then Save.
5. Wait for deployment and use the published URL shown in Settings → Pages.
6. Add the two public page URLs to Discord Developer Portal → your application → General Information.

Before publishing, replace the contact placeholders and make sure the privacy policy matches the bot's real data practices. Only use the cloner for servers and content you own or are authorized to reproduce.
